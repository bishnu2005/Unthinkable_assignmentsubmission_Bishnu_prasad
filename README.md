# Social Media Content Analyzer
An AI-powered application that analyzes social media posts (PDFs and Images) and suggests engagement improvements.

### Features
* **Multi-Format Upload:** Supports PDFs and high-res image carousels (drag-and-drop enabled).
* **AI Vision & Text Extraction:** Uses Groq and Gemini APIs for lightning-fast analysis.
* **Active Failover Architecture:** Built-in backend redundancy automatically routes requests to secondary APIs if primary rate limits are hit.
